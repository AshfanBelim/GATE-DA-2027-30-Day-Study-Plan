# GATE DA 2027 – 30-Day Study Planner

A Python-based visual study planner designed to help students prepare for the GATE Data Science and Artificial Intelligence (DA) 2027 examination. This project generates a clean, calendar-style PNG image featuring a structured 30-day study schedule covering probability and statistics, linear algebra, calculus, programming, data structures and algorithms, databases, machine learning, and artificial intelligence.

Built with Python and Matplotlib, the planner organizes daily topics into a 5 × 6 grid with individual date cards, readable typography, and a professional layout. The generated calendar is saved as a high-resolution PNG image for easy viewing, printing, and sharing.

## Features

- Structured 30-day GATE DA study schedule
- Daily subject and topic breakdown
- Practice and revision sessions
- Calendar-style layout with 30 individual cards
- Clean design with rounded cards and alternating backgrounds
- High-resolution PNG export at 300 DPI
- Automatic creation of the output directory

## Tech Stack

- Python
- Matplotlib
- Python Standard Library (`datetime`, `pathlib`, `textwrap`)

## How to Run

1. Clone this repository.
2. Install the required dependency:

   ```bash
   pip install matplotlib
   ```

3. Run the Python script:

   ```bash
   python gate_da_calendar.py
   ```

4. Find the generated calendar at:

   ```text
   output/gate_da_30_day_plan.png
   ```

## Project Goal

To make GATE DA preparation more organized and accessible through a simple, visual study calendar that helps students plan their daily learning and revision.

**Note:** This project provides a study-planning resource, not an official GATE examination schedule or syllabus document.
